# FlowForge Roadmap

## Release Milestones

| Tag | Scope | Key Laravel Features |
|---|---|---|
| `v0.1.0` | Auth, multi-tenancy, RBAC, tenant onboarding | Sanctum, Spatie Permission, global scopes |
| `v0.2.0` | Workflow CRUD, step CRUD, manual trigger, sync execution engine | Eloquent, API Resources, Form Requests |
| `v0.3.0` | Async execution via queues, Horizon, retry logic, execution logs | Queues, Jobs, Horizon, Events, Listeners |
| `v0.4.0` | AI provider integration (OpenAI + Claude + Ollama), AI step type | Service container, Strategy pattern, HTTP Client |
| `v0.5.0` | Webhook triggers, Connector registry, OAuth connectors | Socialite, encrypted casts, inbound webhooks |
| `v0.6.0` | Scheduled triggers, Notification steps (email, Slack, SMS) | Task Scheduling, Notifications, Mail, Vonage |
| `v0.7.0` | Stripe billing, subscription plans, usage metering | Laravel Cashier, webhooks, middleware |
| `v0.8.0` | React/Vue frontend — workflow builder UI | Inertia.js or SPA with API |
| `v0.9.0` | Flutter mobile app | Dart, Flutter, Sanctum token auth |
| `v1.0.0` | Production Docker, Railway/AWS deploy, CI/CD, monitoring, OpenAPI docs | GitHub Actions, Horizon, Telescope, L5-Swagger |

## Current Status

> `v0.1.0` — in progress
